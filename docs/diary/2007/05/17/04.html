  • 『 Reflections: Carly Simon's Greatest Hits 』 Carly Simon

僕が始めてTVや雑誌のグラビアを見て憧れた方でございます^^　そんなことはいいとして(このジャケ写はよくない！)、今ではあまり聴かれることもないようですが、この人もやはり70年代前半を彩った歌声の一人ですね。"Anticipation"、"You're So Vain"、決してうまくもなく、知的とかいうのではないんだけど、どこか醒めた感じと情熱とが同時に感じられるような歌と曲です。

これまた今ではほとんど話題に出ませんが、当時超売れっ子だったRichard PerryのProduce。バックで耳が行くのはAndy NewmarkのDrumsかな。この人はこういうポップスで似つかわしくないドタバタしたドラムを叩く時だけはかっこいい＾＾；

日本では確か"Anticipation"のB面だったと思いますが、デビュー曲の"That's The Way I've Always Heard It Should Be"もしっとりしていて好きです。
