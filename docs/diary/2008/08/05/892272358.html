期間限定で登場のミクシィの新機能を試してみませんか？ 詳細はこちら↓

http://mixi.jp/guide_echo.pl?access=diary

TwitterとかFacebookの"update status"みたいな一言メッセージ機能。Facebookで使ってmixiにもこういうのあればいいんじゃん？と思ってたので僕的にはタイムリー。

マイミクさんのエコーが表示されて返信もできる、チャットもできるんだけど、それは果たしてどうなのか？ｗ しかしマイミクさんがマイミクさんでない人に返信してる場合はその場では元エコーを確認できないのね。echo = message + reply + reply + reply .... を重視するならフィルタとか履歴とか、充実させなければならない機能はあるだろうが、まあどうなっていくかということで。

これができると、生きてます通信で毎日日記書かなくちゃというプレッシャーから開放されるかなｗ

携帯からは１発でエコー書き込みできたほうがいいな。
