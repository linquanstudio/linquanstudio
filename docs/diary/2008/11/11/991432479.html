ブラポル語志願

mixi日記から転載 id=991432479

フランス語をかじりはじめで継続して触れる必要があるというのに、ブラポル語を覗いてみようかという気になっている。

ブラポル語＝ブラジル・ポルトガル語(português brasileiro)。ブラジルで使われているポルトガル語である。

まあ考えてみるとジョアンもジョビンもこれを話し、これで歌っているのに、今まで知らなくてもいいやと思っていたほうが不思議ともいえるけれども、日本に来ているブラジルの人、数人と触れる機会ができて、喋っているのを聞いているうちに、なんだ、こういう場で試せばすぐ覚えられるんじゃ？と思ったのがきっかけ。

どうもラテン系の言語のほうが相性がよいらしく、今やっているフランス語も楽しくてしょうがないのだが（なんか英語とは気持ちが全然違う）、それはともかく、さっそくWikipediaしてみると…。

ポルトガルのポルトガル語はイベリア・ポルトガル語 ブラジルのポルトガル語はブラジル・ポルトガル語

その違い。

母音、鼻母音、子音、アクセントなど、発音ではいろいろ違いがあるが、これは実際イベリア・ポルトガル語を使う機会はおそらくないので気にしなくてよかろう。ポルトガルに僕が読みたい本を書いた人も確か居ないし。

問題は文法か。

二人称代名詞が変わって単純化しているとか、現在進行形がなんたらとか書いてあるがそれほど大きな違いはなさそうだ。

ふーむ。

サンバやボサノヴァの歌詞以外にブラポル語で書かれた読みたいテキストってのが思いあたらないのがちょっとひっかかる（ボルヘスはアルゼンチンだからスペイン語だよね？パウロ・コエーリョは読んだことないしな…）けど、英語だって始めたときはBeatlesが分かればいいやって感じだったわけだし、とりあえずジョアンの歌が歌えればいいや、くらいでかまわないかと思う。

で。

まず、入力をどうするか。Windows IMEでとりあえず[PT]（ポルトガル語（ブラジル ABNT））をインストールしてみる。フランス語配列と違って、専用のキーがあるのは「Çç」くらいみたいだな。後はデッドキーを使うみたいだ。そもそもどんなアルファベットを使っているかも知らないでやってるんだから無茶苦茶だねｗ

たとえばこのブログを参考にやってみると…

[+] → ç

アクセントは、

[＠]の次に[A][E][I][O][U] → áéíóú [shift]＋[＠]の次に[A][E][I][O][U] → àèìòù

大文字は母音キーのときにも[shift]キーを押す。当たり前か。

[：]の次に[A] → ãÃ [shift]＋[：]の次に[e] → êÊ

とある。どうやらこのくらい入力できればいいらしい。

なるほど、これで入力できるから、あとは適当な入門書やWeb上の講座を探せばいいわけだな。発音も必要だけど、これはどうしたもんかなあ。音楽だけだとサンプル少なすぎ。

ま、ぼちぼち探していけばいいやね。
