月も変わったのでもう放置できん。

前回は、

体重 = 59Kg 体脂肪率 = 17.5% 体脂肪量 = 10.35Kg 除体脂肪量 = 48.68Kg

http://mixi.jp/view_diary.pl?id=1152135265&owner_id=2444430

この辺から、なかなか先に進まない状況が続いていたのですがやっと10回平均で60kgの大台に。

体重 = 60.1Kg 体脂肪率 = 17.2% 体脂肪量 = 10.32Kg 除体脂肪量 = 49.74Kg

体脂肪量変わらず、除体脂肪量が1kg増えたw

グラフで見ると順調に体重増加しているのがわかるな。

これはナ★ディスさんご推奨の四股立ちのおかげのような気がするなあ。 まだ二週間ぐらいのはずですが、見た目にもかなり変化しているように思える。

イチローが四股立ちで胴体をひねって肩を交互にいれるストレッチやってますが、あれができるようになるといいなあ。

ここから除体脂肪を2Kg増やして、体脂肪を600g減らすと61.5Kgの体脂肪率15.8%。

この辺が一つの目標かな。 体脂肪量も10kg切るし。
