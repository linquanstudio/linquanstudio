Carly Simonのこと

mixi日記から転載 id=1146130056

なんかこれも書いたことがあるような気がするんだけどなあ…、mixi日記検索なんとかならんか。

それはともかく、初恋の人です …といっても、メディア通して片思いのケースでですが＾＾；

この人の一番有名なヒット曲は"You're So Vain (from "No Secrets" / 1972)"なんでしょうが、確かその頃日本に来て、テレビに出てピアノを弾き語るのを観たのが馴れ初めかなあ。しかし、"You're So Vain"も大好きですが、なぜかその後別のシングル盤を買ってそのカップリングが気に入ったのでした。"Anticipation"と"That's The Way"。

Carly Simon - Haven't Got Time/ Anticipation/ That's The Way: Live

これは'94年の映像なので、49歳。しかし、雰囲気は全然変わっていないようで、この映像を観てあらためてあー僕のタイプの一方向だなあと納得した次第、三つ子の魂百まで。

音楽的には、まあ、当時からそれほど楽曲に閃きがあるわけでもなく（なにしろ当時はCarole KingだのJoni Mitchellだのが全盛の時代だし、普通の人には分が悪い）、いかにもアメリカのお金持ちの（実際お金持ち出身）ちょっと考えが足りなそうな（ファンの人いたらごめんなさい、僕もファンなんです）キャラで、歌詞もそれほど洗練されてるとも思えず…でも、好きなんだなあ。

そういうキャラもタイプなのかもしれないし、やはりこの声がたまらないんですね。

この動画ではレコードと比べるとだいぶ声が荒れてるというか、シャウトまで行かないけどそれに近い発声のところが多々あって、うたい回しも（まあもともと）荒っぽい感じはあるけれど、また違ったいい雰囲気だと思います。

"That's the way"が確かデビュー曲で、スタジオ盤はもっとしっとり歌っていますが、これもいいですね。で、"Anticipation"。この曲好きだな。歌詞の言葉ののせ方が野暮ったいかな（まあ歌がこなれていないのか）？とか、言葉の選び方が素朴過ぎないか？とかあっても、やっぱりいい曲だしいい歌だと思います。

Carly Simon ANTICIPATION (acoustic)

最近はこんな感じでやっているようで、脇で座ってギターで伴奏している中にどうやらJames Taylorとの間にできた息子がいるらしい…。別の動画でスタバでインストア・ライブをやっているのがあって、そのコメントに書いてありましたが。

この人とJames Taylorが結婚したことは、とうとうつい最近までJames Taylorを真面目に聴かなかったという多大な影響を僕に与えたのですが、考えてみると、Carole King、Joni Mitchellをはじめ数々の女性シンガー・ソングライターと浮き名を流しながら、結果この人と結婚したというのも、なんだか考えさせることではあります。

まあ、全部public imageの中だけの話なんで所詮は妄想の粋を出ませんが。

というわけで、朝から、豆腐の角に頭ぶつけてみたら？とか、いわれかねないような話題でありました。
