BOSE L1 System

mixi日記から転載 id=1072819208

今日近くの楽器屋さんに行って店長とおはなしになった。ギターアンプなんか見せてもらって、いいけどエレキギター弾かないからな～、アコギとベースだし、っていったら「アコギとベース？ならこれでしょう」と指さしたのがこれ。

BOSE L1 Model 1 system

http://www.bose.co.jp/jp_jp?url=/consumer_audio/musicians/l1_systems/l1_m1/l1_m1.jsp

アンプ、4ch mixer、トールボーイ（？）のスピーカーの組み合わせでPAになるシステム。 BOSEお得意のサブウーファーを追加できて、そうすると低音ばっちり。

思わず店内で僕ベース歌店長アコギでセッションしちゃったけどｗ

なんでも小さい会場なら一人一人がこれを使って、メインのPAなしでライブができるそうで、そういうところ、なかなか可能性を感じるシステムである。大会場の大雑把なPAによるライブとはだいぶ違った音場が作れそう。

いちおういろいろとシミュレータらしきものがついていて音も変えられればエフェクトもかけられる。

ただ、それらをやっても、やっぱBOSEの音だな～と思っちゃうのは僕だけだろうか？

まあ、そういうところはともかくとして、おもしろそう。

誰か買ってみない？ｗ
